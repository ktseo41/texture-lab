# 참고용 프리셋

앱의 프리셋 목록에는 넣지 않고 보관만 하는 설정들. 앱에서 `JSON↑` 버튼으로 파일을 불러오면 그대로 적용된다.
파일에 없는 값은 기본값으로 채워지고, 캔버스 크기는 담지 않는다.

- `wave-glass.json` — 분홍·보라·크림 색 덩어리 위 글자에 물결 줄 유리. 글자 획이 물결을 따라 가늘게 흔들린다.
  글자가 들어가서(팩토리 프리셋은 글자를 쓰지 않는다) 프리셋 목록 대신 여기에 둔다.
- `pyramid-prism.json` — 피라미드 격자 유리, 음영 0 + 색 분산 최대. 글자와 윤곽이 삼각 조각과 무지갯빛 테두리로 부서진다.
  원래는 업로드한 사진 위에서 맞춘 유리 값이고(사진은 파일에 담기지 않음), 배경은 `wave-glass.json`과 같은 색 덩어리 + 글자로 대신했다.
  글자가 더 읽히게 하려면 굴절(`fgRefract`)을 45 안팎으로 낮춘다.
